# NikoPDF

PDFを画面共有して、ニコニコ風にコメントを流すサイトです。GitHub Pagesのような静的ホスティングで動きます。PDFはサーバーに保存せず、開いているブラウザ同士で送ります。

## 使い方

1. 最初の画面で「ホストとして始める」を押すと、`/ルームID/host` が開きます。
2. PDFをドロップするか、サンプルを開きます。
3. 表示されている閲覧URL（末尾が `/view`）を相手に渡します。
4. 閲覧側は同じページを見ながらコメントを送れます。コメントは右から左へ、ホストとすべての閲覧画面を流れます。

ページ送りはホストだけが行います。矢印キーでも進めます。拡大縮小は各画面の表示用で、相手の画面には影響しません。

## URL

| 末尾 | 役割 |
| --- | --- |
| `/host` | PDFを開いてページを送る |
| `/view` | 同じページを見てコメントする |

例: `https://makimaki510151.github.io/NikoPDF/abcd2345/host`

リポジトリ名がURLに入る GitHub Pages でも、ユーザーサイトの直下でも、パスから自分の配置場所を判断します。存在しないルームURLは `404.html` がアプリを開くので、共有リンクを直接開けます。

## 公開する

`main` に、ビルド済みの `js/`、`cmaps/`、`standard_fonts/`、`404.html` を含めておきます。

1. リポジトリの Settings → Pages を開く
2. Build and deployment は Deploy from a branch
3. Branch は `main`、フォルダは `/ (root)` にする

公開URLは `https://<ユーザー名>.github.io/NikoPDF/` です。

再ビルドするときは Node.js 20 以降で次を実行し、生成ファイルもコミットします。

```bash
npm install
npm run build
```

## ローカルで動かす

```bash
npm install
npm test
npm run dev
```

`http://127.0.0.1:4173/` を開きます。開発サーバーは `/ルームID/host` のようなアドレスも `index.html` に渡すので、共有URLを直接開けます。

## 通信

- 同じブラウザのタブ同士は、ページをまたいだローカル通信でも届きます。
- 別の端末へは、公開リレーで相手を見つけてから WebRTC で直接送ります。会社のネットワークや対称NATでは、リレーは見つかっても画面が届かないことがあります。
- ルームURLを知っている人は誰でも入れます。秘密にしたい資料のURLは、その場の人だけに渡してください。
- パスワード付きPDFには対応していません。ファイルサイズの上限は 32MB です。
